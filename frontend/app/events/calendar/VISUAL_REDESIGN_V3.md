# Event Calendar Visual Redesign v3

This pass intentionally replaces the dark tile matrix with a light operational calendar surface.

- Day cells are white/light neutral with thin grid separation.
- Green is reserved for today, selected-state accents, and event/status indicators.
- Event rows are compact strips with a colored status edge rather than full-cell fills.
- The empty-state inspector is reduced in visual weight.
- KPI and toolbar surfaces are flatter and more compact.
- Calendar, filter, and inspector typography uses a readable 12–13px floor for operational text.
- Targeted `!important` declarations defend the calendar surface against legacy global button/background rules.
